# Site Manifest

## Overview

A committed JSON manifest lists every deployed site, generated by a scan script and refined by hand-edited overrides.

## User Stories

- As the owner, I want a script to discover my deployed sites so that I don't maintain the list from scratch.
- As the owner, I want to hide, rename, re-categorise or re-describe any site so that I control what visitors see.
- As the owner, I want sites from private repos excluded from the built output so that they never leak.

## Requirements

- [ ] `npm run sites:scan` writes `data/sites.generated.json`
- [ ] Sources, in order of trust: (1) `gh repo list` metadata (name, description, homepageUrl, language, privacy, pushedAt); (2) local `C:\code\*` folders (`.netlify/state.json`, `netlify.toml`, README/CLAUDE.md URLs matching `*.netlify.app`, `*.azurewebsites.net`, `*.pages.dev`, `*.github.io`, `*.vercel.app`); (3) Netlify CLI/API to resolve a site id to a URL when only `.netlify/state.json` exists (token from env, never committed)
- [ ] Each URL found is verified with an HTTP HEAD/GET, and non-2xx sites are flagged `status: "dead"` rather than dropped
- [ ] Manifest entry shape (validated with Zod): `id`, `name`, `url`, `repo`, `description`, `category`, `tags[]`, `language`, `isPrivateRepo`, `lastPushed`, `thumb?`, `hidden?`, `accent?`
- [ ] `data/sites.overrides.json` is deep-merged over generated data (override wins); an override can also add sites with no repo
- [ ] The scan sets `hidden: true` on every entry whose repo is private (`isPrivateRepo`), and on no others by default
- [ ] `hidden: true` entries are removed at build time (Vite plugin or build step), not just filtered in the UI
- [ ] Categories derived by heuristic then overridable. Starting set: Games, Learning, Wellbeing, Local (Chelmsford), Tools, 3D & Visual, Parliament
- [ ] Scan is idempotent and produces stable key ordering for clean diffs
- [ ] Scan prints a report: new sites, dead URLs, repos with no discoverable URL

## Acceptance Criteria

- [ ] Running the scan on this machine yields >= 25 entries with live, verified URLs
- [ ] A site marked hidden in overrides is absent from `dist/` entirely (grep test)
- [ ] Zod schema rejects a malformed manifest with a readable error
- [ ] Unit tests cover merge precedence, URL extraction and category heuristics

## Out of Scope

- Live API calls at runtime in the browser
- Automatic scheduled re-scans (post-MVP: GitHub Action)
